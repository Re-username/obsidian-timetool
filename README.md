# TimeTool — плагин Obsidian (время и даты)

Калькулятор времени и дат внутри Obsidian: команды вставляют результат в заметку
в формате Markdown. Дубликат функционала десктоп/андроид-приложения TimeTool.

## Установка

1. Скопируйте папку плагина в хранилище:
   `<Ваше хранилище>/.obsidian/plugins/timetool/` — файлы `main.js` и `manifest.json`.
2. Obsidian → Настройки → Сторонние плагины → отключите «Ограниченный режим».
3. В списке появится «TimeTool — время и даты» — включите.

## Команды (Палитра команд: Ctrl+P → «TimeTool»)

- **Разница между моментами** — две даты-времени → `**Разница:** 9 часов 0 минут (0,38 дней / 9,0 ч)`.
- **Сдвиг даты** — дата ± интервал (минуты/часы/дни/недели/месяцы/годы) → `**17.11.2026 21:28** + 14 дн. = **01.12.2026 21:28**`.
- **Отсчёт до даты** — дата → `**До 01.12.2026:** осталось 14 дней`.
- **Сумма интервалов (смены)** — строки «начало—конец» (переход через полночь учитывается) → `**Сумма интервалов:** 10 часов 0 минут (10,0 ч)`.

Результат вставляется в позицию курсора.

## Разработка

```bash
npm install
npm run build   # tsc --noEmit + esbuild → main.js
```
